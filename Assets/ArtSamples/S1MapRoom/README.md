## 正式地图按这间样板同步

一条条对着这间样板改正式地图。样板里没有的，不从这间里抄。

1. 房间改成 28×22。角色缩放仍是 1，PPU 仍是 128，正常镜头仍是 size 6。
2. 地面以中央安静地砖为主，磨损和破损只沿墙脚和行走方向稀疏铺。祭坛、宝箱、入口各自一块局部铺地。
3. 墙用连续石面，檐口和墙基要有厚度。四周不要再逐块拼出锯齿透明边。
4. 入口留立柱和净通行口。样板没有开关门。正式地图锁住时用拱门关上，不要把一张门拉成整条高墙，也不要留成空开口。
5. 火盆、碎石成组摆在墙边。每间房一个主要焦点。样板把宝箱、祭坛和敌人放在同一间，只为对照比例。正式房间按用途拆开，不每间都摆全套。
6. 地上不写房间名字。小地图不在这间样板里。正式小地图中央是玩家，不写 START、ALTAR 这种字。
7. 弓手用现有八向走路。走路是否平稳另按角色任务改，不在这间样板里重做。

## 本轮实际制作

当前场地范围 28×22，角色缩放 1、PPU 128 和正常镜头 size 6。中央安静地砖占主导，磨损/破损稀疏分布；祭坛、宝箱和入口分别有局部铺地和暖色焦点。墙边有五组碎石、场景内有五处动态火焰。

北墙重新用连续网格承载现有墙片的内部石面，檐口、浅壁柱及侧面低墙为样板专用可编辑网格。这样保持矩形房间边界，不再把等距墙片的透明锯齿轮廓逐块拼满四周。入口保留立柱和净通行口。样板没有开关门。正式地图锁住时另做拱门关上，不把这道开口当成完成的门。侧墙采用低细节剖面，入口外侧地砖的菱形边沿仍可见；这两处随地图同步一起精修。

所有内容保存在层级中，地面是可编辑 Tilemap；不是一张整房背景图。可在编辑器调整摆位和配色。菜单 `JianHai > Art Samples > Build S1 Map Room` 可重建默认样板；重建会覆盖本样板的摆位，手工改版请另存场景。
